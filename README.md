# FORGE
Digital Fabrication app
FORGE is a single-file, offline, browser-native fabrication console that converts a 3D mesh (STL/OBJ) into laser/plasma/CNC-cuttable flat parts by four methods — unfold, contour section, egg-crate waffle, and radial fin-and-ring — then nests them onto stock sheets with self-intersection-safe cut paths, fragility flags, and SVG/DXF/PDF/G-code export.
